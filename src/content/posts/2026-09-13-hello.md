## 왜 만들었나

이력서와 기술 글을 한 곳에서 관리하기 위해 이 사이트를 만들었습니다.
Markdown 파일 하나가 글 한 편이고, `git push`하면 자동으로 배포됩니다.

## 구성

- 호스팅: GitHub Pages (무료)
- 생성기: Astro + AstroPaper 테마
- 이력서: Markdown 1개로 웹 페이지와 PDF를 동시에 생성

## 글 추가 방법

`src/content/posts/` 아래에 `YYYY-MM-DD-제목.md` 파일을 만들고 위와 같은 frontmatter를 채운 뒤 push하면 끝입니다.
